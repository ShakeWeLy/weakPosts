## 3 优化

### 3.1 image层优化

####   1 层优化减少不必要的层+命令和并

```
# 不推荐：每个命令都会创建新层
RUN apt-get update
RUN apt-get install -y python3
RUN pip install numpy
RUN pip install opencv-python

# 推荐：合并RUN命令
RUN apt-get update && \
    apt-get install -y python3 && \
    pip install numpy opencv-python && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/*
```
